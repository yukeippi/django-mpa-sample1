# ADR-0002: アプリ内で共有するコードは規模によらず app/lib/ に置き、トップレベルへの移動は人が決める

Status: Accepted
Date: 2026-09-23

## 背景

規約(Common Module Rules)には「`app/lib/` 配下のモジュールが肥大化し、独立したサブシステムと呼べる規模になったら、トップレベルディレクトリへ昇格してよい」という規則があり、`app/permissions/` がその例だった。ディレクトリ構成を見直す中で、`app/permissions/` を `app/lib/` に移すことを検討し、あわせてこの昇格の規則を見直した。

## 決定

アプリ内で共有するコードは、規模によらず `app/lib/` の下に置き、大きくなったらその中でディレクトリを切る。トップレベルへ移すかどうかは AI の判断では行わず人が決める。既にトップレベルにある `app/permissions/` は、人の判断で移したものとしてそのまま残す。詳細は `.claude/instructions.md` の Common Module Rules。

## 却下した案

- 規模で昇格を判断する規則を残す(テンプレートの元方針。例を差し替えて使い続ける案を含む)
  → ルールをシンプルにし、後から変更する余地を残したい。まずは `app/lib/` に集約し、トップレベルへの移動は人の判断で行いたい。トップレベルには、できるだけ Django 標準でないファイル・ディレクトリを置きたくない

## 影響

`.claude/instructions.md` の Common Module Rules(昇格の規則を置き換え、末尾に `経緯: ADR-0002`)と Test Layer Rules(昇格したディレクトリの項目の書き方)を更新。コードの移動は無い。
