# 仕様: 社員の所属部門を割り当てる

> この仕様は作成日時(ファイル名の先頭)の時点の記録です。完了後は更新しません。現在の挙動の正本はコードとテストです。

## 社員詳細画面(GET /employees/<pk>/)
- 所属部門の一覧(会社名 / 部門名、主務か兼務か)が表示される。所属が無い場合は「所属部門はありません」と表示される
- 全社管理者にだけ、「所属部門を追加」と各行の「外す」が表示される

## 所属部門の追加
- 部門を選び、主務か兼務かを選んで追加できる。追加後は社員詳細画面にリダイレクトされ、「所属部門を追加しました。」と表示される
- 既に所属している部門は追加できない(「この社員は既にこの部門に所属しています。」を表示し、所属は増えない)
- 既に主務がある社員に、別の部門を主務として追加することはできない(「この社員には既に主務の部門があります。」を表示し、所属は増えない)
- 既に主務がある社員に、別の部門を兼務として追加することはできる
- 主務は1人1つまで(画面を通らない保存でもDBで守る)
- 主務が無い社員がいてもよい(兼務だけ、または所属なし)

## 所属部門を外す
- 所属を外すと、社員詳細画面にリダイレクトされ、「所属部門を外しました。」と表示される
- 主務も外せる(外した後は主務なしになる)
- 外すのはPOSTのみ(GETでは外れない)

## 権限
- 追加・外すことができるのは全社管理者だけ(全社管理者の管理グループ(is_admin)のメンバー)
- 全社管理者でないユーザーが追加・外すを行うと403になり、所属は変わらない
- 存在しない社員・存在しない所属は404
- URLの社員と、外そうとした所属の社員が違う場合も404になり、所属は変わらない(存在しない所属と同じ扱い)
- 未ログインの場合はログインページにリダイレクトされる

## 対象外
- 既存の所属の主務/兼務の切り替え(外してから追加し直す)
- 部門詳細画面からの割り当て
