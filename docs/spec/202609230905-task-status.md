# 仕様: タスク詳細画面のステータス変更(モーダル)

> この仕様は作成日時(ファイル名の先頭)の時点の記録です。完了後は更新しません。現在の挙動の正本はコードとテストです。

## 画面(詳細画面)
- 編集権限のあるユーザー(管理者・作成者・担当者)には、ステータスの横に「変更」ボタンが表示される
- 編集権限の無いユーザーには「変更」ボタンもモーダルも表示されない
- 「変更」を押すとモーダルが開き、現在のステータスが選択された状態のセレクトが表示される

## ステータス変更(POST /tasks/<pk>/status/)
- 編集権限のあるユーザーはステータスを変更でき、詳細ページにリダイレクトされ、「タスクを更新しました。」と表示される
- ステータス以外の項目(タイトル・説明・優先度など)は変わらない
- 選択肢に無い値を送った場合は変更されず、詳細ページにリダイレクトされ、エラーメッセージが表示される
- 編集権限の無いユーザーは変更できない(403、状態は変わらない)
- 存在しないタスクは404
- 未ログインの場合はログインページにリダイレクトされる
- GETでアクセスした場合は405(画面を持たない)

## E2E
- 詳細画面で「変更」→ モーダルでステータスを選んで保存 → 詳細画面のステータス表示が変わる
