# Meta.orderingの廃止

並び替えが不要なクエリにまで暗黙のORDER BYが付くのを防ぐため、Meta.orderingを使わず、必要なクエリでorder_by()を指定する。

## 並び順を指定する(今と同じ並びを保つ)

1. 会社一覧は、会社名順に並ぶ
2. 部門一覧は、会社名順、同じ会社の中では部門名順に並ぶ
3. 社員一覧は、社員番号順に並ぶ
4. 管理グループ一覧は、名前順に並ぶ
5. タスク一覧は、作成日時の新しい順に並ぶ
6. 部門フォームの「会社」の選択肢は、会社名順に並ぶ
7. 管理グループフォームの「部門」の選択肢は、会社名順、同じ会社の中では部門名順に並ぶ
8. 会社詳細に表示する部門は、部門名順に並ぶ

## 並び順を指定しない

9. タスクAPI(/api/tasks/)はORDER BYを付けない(E2Eテスト用で並び順を求めていない)

部門詳細の所属社員、管理グループ詳細のメンバーは、元から並び順の指定が無いためそのまま。
