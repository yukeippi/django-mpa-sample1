# 仕様: タスク一覧から右ペインで詳細を表示する

> この仕様は作成日時(ファイル名の先頭)の時点の記録です。完了後は更新しません。現在の挙動の正本はコードとテストです。

## 一覧画面
- 一覧の行をクリックすると、画面は移動せず、右からペインが開き、クリックした行のタスクの詳細(タイトル・説明・ステータス・優先度・担当者・作成者・期限)が表示される
- ペインを開いたまま別の行をクリックすると、その行のタスクの詳細に切り替わる
- ペインを開いている間も、一覧をスクロールできる
- ペインは × か Esc で閉じる。一覧をクリックした後でも Esc で閉じられる。ペインの外をクリックしても閉じない
- ペインのフッターには、編集権限のあるユーザー(管理者・作成者・担当者)にだけ「編集」、削除権限のあるユーザーにだけ「削除」が表示される
- ペインのフッターの「詳細ページを開く」から、詳細画面に移動できる(ステータス変更は詳細画面で行う)

## ペインの中身(GET /tasks/<pk>/pane/)
- ログインしていれば、誰のタスクでも表示できる(詳細画面と同じく、閲覧に所有者の制限は無い)
- 存在しないタスクは404
- 未ログインの場合はログインページにリダイレクトされる

## 変わらないこと
- 詳細画面(/tasks/<pk>/)は今までどおり直接開ける。作成・編集後のリダイレクト先も詳細画面のまま
